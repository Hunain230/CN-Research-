# Task 7 Submission Package

## Goal

Assemble a coherent submission from the work actually completed, with the research question, method, evidence, results, limitations, and reproducibility instructions aligned.

## Steps

1. Read the completed cleanup record, data/claim audit, experiment register, synthetic MVP runner record, results/discussion, and dashboard verification.
2. Draft `submission/FINAL_REPORT.md` with a clear title, abstract, problem/topic, related work, research gap, methodology, implementation, experimental setup, results, discussion, limitations, conclusion, and references.
3. Keep planned methodology distinct from implemented methodology. State plainly that the original C/P/V LLM study has not been empirically completed if that remains true.
4. Include course deliverables for Phases 1–4: data validation, safe preprocessing, baseline implementation status, and agent-system implementation status. State which validations were synthetic and which analyses used real data.
5. Include only valid figures and aggregate tables. Cite their source artifacts and preserve every caveat about exploratory status and assumptions.
6. Add `submission/REPRODUCE.md` with environment, exact commands, expected outputs, and which commands are synthetic checks versus real-data exploratory runs.
7. Add `submission/KNOWN_LIMITATIONS.md` listing unresolved gates, unavailable comparisons, and what evidence would be needed to clear them.
8. Check internal links, spelling, section consistency, metric values, captions, and references. Ensure the report, dashboard, and README use the same terminology and status.
9. Provide a final handoff summary stating which items are complete, blocked, and not attempted. Do not claim that the class will accept the work; the instructor determines that.
