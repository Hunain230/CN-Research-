# Phase 3 delivery checklist

**Updated:** 2026-11-14. This checklist maps the supplied Phase 3 implementation brief to concrete artifacts. “Complete” means implemented and evidenced for the stated scope; it does not imply the research target or production gates passed.

| Requirement | Artifact and status |
|---|---|
| Proposed method implementation | **Partial.** [Local Qwen v2 C/P/V prototype](../src/submission_local_qwen_v2.py) runs C, P, V with localhost `qwen2.5:3b` on frozen selected pairs in 20 organizations. It batches calls and omits the full revision loop and full-dataset model pass. [Synthetic C/P/V plumbing](../src/mvp_demo.py) remains a separate software demonstration. |
| Dataset description and preprocessing | **Complete for exploratory use.** [Data audit](DATA_AND_CLAIM_AUDIT.md) records evidence-row grain, key ambiguity, queue labels, field gate, and raw hashes. [Full offline implementation](../src/submission_full_guide.py) scans all GUIDE_Test evidence rows and excludes ambiguous keys. |
| Baseline evaluation | **Partial.** [Rerun full offline count and BM25-like metrics](../outputs/submission_full_guide_paper_20261113_v1/metrics.json) cover all 499 ranked organizations. [Paired Qwen v2 C/B2 metrics](../outputs/submission_qwen_v2_paper_20261113_v1/metrics.json) cover 240 selected exact-match pairs with 22 positives; C pair recall was 1/22, B2 was 2/22. B2 has no component ranking. Original detector-severity B0, matched B3/B4, and full empirical C/P/V comparison are unavailable. |
| Graphs and quantitative results | **Complete for recorded scope.** [Task 5 figures](figures/figure_manifest.json) cover prior matched proxies, candidate losses, and oracle ablation. The [full-run figure](figures/full_guide_offline.png) and [paired Qwen figure](figures/qwen_v2_pair_diagnostic.png) show separate scopes with [source hashes](figures/qwen_v2_figure_manifest.json). |
| Comparable existing research | **Qualified.** [Final report](FINAL_REPORT.md) cites GUIDE and Adaptive Incident Prioritization and explains the different tasks and denominators. It makes no unsupported direct performance comparison to published headline scores. |
| Ablation and discussion | **Partial.** [Earlier oracle-group ablations](RESULTS_AND_DISCUSSION.md) and the new shared-group ranker contrast are discussed. A matched model-role ablation on the full dataset remains unavailable. |
| Final implementation report | **Complete as an exploratory submission package.** [Print-ready PDF](PHASE3_IMPLEMENTATION_REPORT.pdf), [editable report](FINAL_REPORT.md), [PDF source/hash manifest](PHASE3_REPORT_PDF_MANIFEST.json), [reproduce instructions](REPRODUCE.md), [experiment register](EXPERIMENT_REGISTER.md), and [known limits](KNOWN_LIMITATIONS.md). |
| Dashboard simulation | **Static build verified; interactive QA open.** [Fictional playback](../dashboard/simulation.html), [source manifest](../dashboard/simulation_manifest.json), and [verification record](DASHBOARD_VERIFICATION.md). |
| Operational measurements | **Partial, retrospective.** [Local batch diagnostic](../outputs/submission_qwen_v2_paper_20261113_v1/operational_diagnostics.json) measures call p50/p95/max latency, model-call failure rate, selected-pair processing rate, abstention, and review load from the frozen Qwen trace. Alert-to-decision latency, sustained live throughput, analyst outcomes, and uptime remain unmeasured. |

**Research decision:** This package supports a scoped exploratory Phase 3 implementation demonstration if partial requirements are acceptable. It is not a complete implementation of the proposed held-out, matched C/P/V study, a confirmatory claim that it outperforms baselines, or an operational SOC evaluation. The full offline candidate-recall gate is failed; the model run is deliberately bounded and local-only. The Phase 2 document itself calls for an offline study and places live SOC productivity in a future field study.

**Verification record:** The user-operated runner completed the 499-organization offline pass and 20-organization Qwen v2 pass. Both new manifests verified against their recorded hashes; the new offline metrics hash matches the prior full run. The software self-checks passed, including 4 full-offline and 2 Qwen-v2 evaluator assertions. Aggregate figure generation passed. The five-page A4 report PDF was rendered and visually checked. Static dashboard syntax and local HTTP checks passed; interactive browser QA is still open. No claim of instructor acceptance is made.
