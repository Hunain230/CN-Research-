# Evidence-aware incident reconstruction paper

Manuscript source: `main.tex`; primary results: `figure_data/holdout_metrics.csv`; original immutable outputs in `../experiments/PHASE33_FROZEN_GENERALIZATION/`.

From repository root: `python paper/build_paper.py` verifies the sealed prediction SHA-256 hashes and metric sums and regenerates the nine vector figures. The detailed methodology and provenance diagrams and the two diagnostic charts are sourced in `figure_source/expanded_figures.py`, which the build script runs. `python paper/audit_paper.py` refreshes claim and source audits without changing experiment files. With MiKTeX/TeXworks, open `paper/main.tex`, select `pdfLaTeX+MakeIndex+BibTeX`, and typeset; repeat pdfLaTeX if cross-references remain unresolved. Alternatively, from `paper/` run `pdflatex main.tex`, `bibtex main`, then `pdflatex main.tex` twice. Copy `main.pdf` to `research_paper.pdf`. Required packages: geometry, lmodern, microtype, ragged2e, setspace, graphicx, booktabs, tabularx, array, amsmath, amssymb, caption, subcaption, float, xcolor, hyperref, natbib.

The final manuscript uses "frozen synthetic holdout" rather than internal phase identifiers. Internal audit paths retain phase names. The PDF is compiled with the installed MiKTeX TeXworks user interface. The sandboxed command-line MiKTeX process cannot access its per-user registry configuration, so the UI is used for the final build. Figure source is editable Matplotlib code in `build_paper.py` and `figure_source/expanded_figures.py`; numerical figure data are in `figure_data/`. The original experiment artifacts are never overwritten by this procedure.
